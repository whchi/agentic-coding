# Grilling

Find the assumptions and choices that could change the plan. Track dependencies between decisions so that a question does not rely on an answer the user has not given.

Inspect available facts yourself. Ask the user for preferences, priorities, and consequential decisions the evidence cannot resolve. Include a recommended answer and its tradeoff.

Work in manageable rounds. Bundle independent questions when that saves a turn; defer dependent ones until their prerequisites settle. Do not enumerate every possible branch or require the user to decide routine reversible details.

Finish when the plan is coherent and the consequential choices are settled, or clearly name what input remains. Summarize the decisions and any residual assumptions. An interview request alone does not authorize implementation; when the user has already asked for implementation too, continue within that scope without a redundant confirmation.
