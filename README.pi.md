# Pi Packages

Installed globally for Pi in `~/.pi/agent/npm`:

| Package | Version | Purpose |
| --- | ---: | --- |
| `context-mode` | `1.0.169` | Context-saving sandbox execution, FTS5 knowledge base, and intent-driven search |
| `pi-mcp-adapter` | `2.18.0` | Discover and call MCP tools from Pi with lazy server connections |
| `pi-web-access` | `0.17.1` | Web search, URL/GitHub/PDF fetching, and video analysis |
| `pi-subagents` | `0.40.0` | Delegate work to child agents with chains and parallel execution |
| `pi-rtk-optimizer` | `0.9.0` | Rewrite shell commands and compact noisy tool output |
| `pi-lens` | `3.8.74` | Real-time code feedback with LSP, linters, formatters, type-checking, and structural analysis |
| `@juicesharp/rpiv-todo` | `2.3.1` | Live todo overlay that survives `/reload` and conversation compaction |

## Installation commands

```bash
pi install npm:context-mode
pi install npm:pi-mcp-adapter
pi install npm:pi-web-access
pi install npm:pi-subagents
pi install npm:pi-rtk-optimizer
pi install npm:pi-lens
pi install npm:@juicesharp/rpiv-todo
```
